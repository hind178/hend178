# موجز البورتفوليو — هند

> المرحلة 01 من الدليل: حدّد الهدف قبل الشكل.
> كل ما بين [أقواس مربعة] أو موسوم بـ «للتأكيد» = معلومة لازم هند تراجعها أو تستبدلها قبل النشر.

## الجملة الأساسية
بساعد **المهتمين بالأسواق والمعرفة** في **بناء أنظمة تحليل وأتمتة بمساعدة الذكاء الاصطناعي، ومحتوى معرفي منظّم**، وبعرض هون **ثلاثة مشاريع شخصية توضّح طريقة تفكيري: من الفكرة للنظام.**

## البنود
| البند | المعلومة المعتمدة |
|---|---|
| الاسم | هند |
| التخصص | بناء أنظمة تحليل وأتمتة بمساعدة الذكاء الاصطناعي + محتوى معرفي منظّم |
| الجمهور | متداولون أفراد ومهتمون بالأتمتة؛ قرّاء يبحثون عن محتوى معرفي واضح؛ أصحاب مواقع معلوماتية |
| الإجراء الرئيسي | إرسال وصف فكرة/مشروع بالبريد |
| الرسالة | «من الفكرة للنظام: تحليل واضح، وأتمتة قابلة للفحص.» |
| الأعمال | ميزان (نظام تحليل فوركس) — بيان (دراسة مفردات قرآنية) — نبع (موقع محتوى معلوماتي) |
| التواصل | hello@example.com ← **عنوان تجريبي، استبدليه قبل النشر** |
| الموقع الجغرافي | العراق — إقليم كوردستان [للتأكيد: هل تريدين ذكره؟] |

## قواعد الصدق (من الدليل)
- لا شهادات عملاء، لا أرقام أرباح، لا نسب نجاح، لا جوائز.
- كل مشروع موسوم «مشروع شخصي».
- نظام الفوركس يُعرض كأداة دعم قرار، **مش** كوعد بأرباح.
- الرسومات في `assets/` مؤلَّفة لهذا التدريب؛ استبدليها بلقطات حقيقية من شغلك.

## ما زال ناقص (أسئلة لهند)
1. البريد الحقيقي أو رابط التواصل المفضّل.
2. لقطات حقيقية من: ملف Excel/الروبوت، صفحات الدراسة القرآنية، موقع الينابيع.
3. هل في رابط فعلي لموقع مياه الينابيع؟
4. الأدوات الفعلية المستخدمة في نظام الفوركس (MT4/MT5؟ Python؟ Excel؟) — مكتوبة حاليًا بشكل عام.
5. سنة كل مشروع.
