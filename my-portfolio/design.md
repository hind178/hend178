# الاتجاه البصري — design.md

> المرحلة 03: قرارات قليلة، تطبيق ثابت. الموقع إطار هادئ؛ الألوان القوية تجي من الأعمال نفسها.

| العنصر | القرار |
|---|---|
| الخلفية والنص | ورق دافئ `#F1F0EA` وحبر `#161616` — محايد حتى ما ينافس ألوان التغليف |
| اللون المساعد | برتقالي `#FF652F` للأزرار (نص داكن فوقه)، و`#B83E12` للنصوص الملوّنة الصغيرة |
| خلفيات الأعمال | لون فاتح مأخوذ من كل عمل (وردي لشيرين، بيج لمجد…) خلف الصورة مع ظل خفيف |
| الخط | Alexandria متغيّر، محلي داخل `assets/fonts` (رخصة OFL مرفقة) |
| المسافات | 8، 16، 24، 40، 64 بكسل |
| الصور | WebP، أبعاد مكتوبة، `loading="lazy"` لكل شي تحت أول شاشة |
| الاتجاه | `dir="rtl"`، البريد والروابط اللاتينية داخل `<bdi dir="ltr">` |

## ترتيب الصفحة
1. البداية: الاسم، التخصص (تغليف ومطبوعات بثلاث لغات)، زر الأعمال، وعمل قوي كصورة
2. أعمال مختارة: شيرين بعرض كامل (لها صفحة)، ثم 6 بطاقات
3. عنّي وطريقة العمل
4. تواصل: البريد الحقيقي
