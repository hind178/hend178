# الاتجاه البصري — design.md

> النسخة الثانية (فرع `redesign`): Modern / Minimal / Editorial. الموقع إطار هادئ؛ الألوان القوية تجي من الأعمال نفسها.

| العنصر | القرار |
|---|---|
| الخلفية والنص | خلفية فاتحة `#FAF9F6`، أسطح بيضاء `#FFFFFF`، حبر `#18181A`، نص ثانوي `#57554F` |
| اللون المساعد | برتقالي محروق `#B8441A` للكلمات المميّزة والعناوين الصغيرة (تباين 5.1:1)، وخلفيته الفاتحة `#FBEADF` للوسوم |
| الأزرار | أسود ممتلئ (أساسي) وإطار فقط (ثانوي)، شكل كبسولة، ارتفاع 52px |
| الزوايا | 10 / 16 / 24 بكسل |
| بطاقات الأعمال | عمودان على الكمبيوتر وعمود واحد على الهاتف، صورة 4:3 على لون فاتح مأخوذ من العمل، تكبير خفيف عند hover |
| الخط | Alexandria متغيّر، محلي داخل `assets/fonts` (رخصة OFL مرفقة) |
| المسافات | 8، 16، 24، 40، 64، 104 بكسل |
| الحركة | ظهور تدريجي خفيف عند التمرير، ويتوقّف مع «تقليل الحركة» |
| الصور | WebP، أبعاد مكتوبة، `loading="lazy"` لكل شيء تحت أول شاشة |
| الاتجاه | `dir="rtl"` للعربي و`ltr` للإنجليزي، والأسهم تنعكس تلقائيًا |

## ترتيب الصفحة الرئيسية
1. البداية: العنوان، التعريف، «شاهد أعمالي» و«ابدأ مشروعك»، وصور من 3 مشاريع حقيقية
2. المشاريع: تصفية (الكل / التغليف / الرقمي / المطبوعات والملفات) + 6 مشاريع + «استكشف المزيد»
3. الخدمات: 4 خدمات، لكل خدمة روابط لأمثلة حقيقية
4. عنّي: النبذة + 6 مجالات خبرة + طريقة العمل
5. التواصل: البريد + زر إرسال + زر نسخ

## صفحة المشروع
نظرة عامة → التحدي → النهج → المخرجات → المعرض → ملاحظات → دعوة للتواصل → المشروع السابق/التالي.
كل النصوص والصور ووصف الصور منقولة حرفيًا من الصفحات السابقة.
