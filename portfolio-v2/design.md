# الاتجاه البصري — النسخة الثانية (v2)

> مستلهم من الأسلوب العام لمواقع منصّات بناء المواقع الحديثة (مثل صفحات Squarespace): أبيض وأسود، عناوين ضخمة، مساحات واسعة، صور بعرض كامل، أزرار سوداء مدوّرة. الكود والنصوص مكتوبة من الصفر؛ لا شيء منقول من أي موقع.

| العنصر | القرار |
|---|---|
| الألوان | أبيض `#FFFFFF`، حبر `#0A0A0A`، سطح رمادي `#F3F3F1`، نص ثانوي `#5E5E5E`، خطوط فاصلة `#E4E4E2` — الألوان كلها تجي من الأعمال |
| العناوين | Alexandria بوزن 800، حجم يصل 8.5rem في الرئيسية، تباعد أحرف سالب للإنجليزي فقط |
| الأزرار | حبّة سوداء (`border-radius: 999px`) + زر بحدود فقط |
| الصور | بدون قص على الموبايل؛ تكبير خفيف عند المرور على بطاقات الأعمال |
| القوائم | صفوف مفصولة بخطوط رفيعة بدل النقاط (القرارات، الخدمات، الخطوات) |
| بدون JavaScript | كل شي HTML وCSS |

## الرئيسية
1. عنوان ضخم + سطر تعريفي + زرّان
2. صورة بعرض كامل (SARAV)
3. أعمال مختارة: شيرين بعرض كامل، ثم 9 بطاقات بعمودين
4. «ماذا أصمّم»: 4 صفوف مرقّمة (قسم جديد)
5. عنّي: جملة كبيرة + طريقة العمل
6. تواصل: قسم أسود ببريد ضخم
